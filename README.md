# Central Region Dashboard (Power BI)

An interactive Power BI report focused on the Central Region slice of the Superstore dataset, built to track sales trends, category performance, and state-level results in one place.

## What's inside
- **Overview page** — sales, profit, average order value, and total orders as KPI cards
- **Sales trend** chart showing performance over time, with a filter panel (date, sub-category, ship mode)
- **Category and state breakdown** — bar chart by category, plus a map showing performance by state
- Drill-through pages for deeper category-level analysis

## Dataset
Central Region subset of the Superstore dataset — orders, products, and sales data filtered to the Central US region.

## Tools
Power BI (Power Query for data cleaning, DAX for calculated measures, interactive visuals and slicers)

## What I learned
- How to model relationships between multiple tables in Power BI's data model
- How a DAX measure's result changes depending on filter context — especially once slicers and drill-throughs are involved
- Building a filter panel that lets a non-technical user explore the data without needing to understand what's happening underneath

## How to view it
Download the `.pbix` file and open it in Power BI Desktop (free, Windows only) to interact with the filters and drill-throughs.
